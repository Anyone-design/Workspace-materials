3. **5 State Transitions:** Map the core loop across all 5 states: Idle, In-Flight, Success, Degraded/Partial, and Error/Recovery.
4. **Scope Creep Pushback:** Execute the 3-step script: Acknowledge Value $\rightarrow$ Quantify Friction $\rightarrow$ Quarantine to Backlog.
